# Event Management System

A full-stack Event Management System designed to simplify event creation, management, registration, and attendee coordination through a modern and user-friendly web interface.

## Overview

The Event Management System provides a centralized platform for creating and managing events while allowing users to browse available events and register for them.

The system helps streamline event organization by keeping event details, registrations, attendees, and event analytics organized in one place.

## Features

* User authentication and authorization
* Admin dashboard
* Create and manage events
* View upcoming and available events
* Event search and filtering
* Event registration
* Attendee management
* Manage event details
* Track event registrations
* Event analytics and reporting
* Organized event information
* Responsive and user-friendly interface
* Event activity management

## Architecture

The application follows a client-server architecture:

* **Frontend:** React.js handles the user interface and client-side functionality.
* **Backend:** Node.js and Express.js provide RESTful APIs and application logic.
* **Database:** MongoDB stores event, user, registration, and attendee-related data.
* **API Communication:** The frontend communicates with the backend through REST APIs.

## Purpose

The main purpose of this project is to provide a centralized solution for managing events, registrations, attendees, and event-related activities while maintaining a simple and responsive user experience.
